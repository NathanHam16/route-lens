# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report them privately using one of these channels:

1. **GitHub private security advisory (preferred):** [Create a security advisory](https://github.com/NathanHam16/route-lens/security/advisories/new) on this repository.
2. **Email:** Contact the maintainer via the email listed on their [GitHub profile](https://github.com/NathanHam16) or npm account.

Include:

- A description of the issue and its impact
- Steps to reproduce
- Affected versions
- Any suggested fix, if you have one

We aim to acknowledge reports within a few business days and will coordinate disclosure and a fix before any public announcement.

## What not to file publicly

Do not post the following in public issues, discussions, or pull requests:

- Exploits, proof-of-concept code, or step-by-step attack instructions
- Unpatched vulnerability details that could affect users
- Credentials, tokens, or private repository paths from your environment

Use the private channels above instead.

## Scope notes

`route-lens` is a **development-only** tool. It is intended for local use and should not be exposed in production deployments. Vulnerabilities that require production exposure or misconfiguration outside documented dev usage may be treated as lower severity, but we still welcome responsible reports.
